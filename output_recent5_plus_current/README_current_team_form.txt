FORME ACTUELLE NHL — SAISON 2026-27

Données arrêtées au 2026-11-13. Une ligne par équipe (32 équipes).
Les fenêtres 5/10/15 utilisent les derniers matchs terminés de la saison en cours.
Les buts sont ceux après 60 minutes. Les tirs cadrés viennent du total NHL GameCenter.
Les métriques basées sur les événements PBP (Corsi, Fenwick, hits, turnovers, mises au jeu, pénalités)
n’utilisent que les matchs où les tirs cadrés PBP concordent avec le total NHL. Les matchs exclus
sont comptés dans matches_in_lastN mais pas dans valid_pbp_games_lastN.
Les statistiques 5v5 utilisent le code strict 1551 et sont calculées uniquement sur les matchs
PBP validés. Les parts et pourcentages sont exprimés sur une échelle de 0 à 100.
